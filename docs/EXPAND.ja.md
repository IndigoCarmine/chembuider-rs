# chembuider-rs Expand機能 全フラグメント一覧

[SHORTCUTS.ja.md §2-4](SHORTCUTS.ja.md#2-4-expandlabel-x--x-ラベルからフラグメントへの展開) で
説明した **ExpandLabel（`x` / `X`）**機能で展開できる、全フラグメント名のカタログです。
「フラグメント名」とは、原子ラベルを `` ` `` 編集でこの文字列に書き換えたのち `x`/`X` を押すと
実構造に展開される、完全一致（大文字小文字区別）の識別子です。

対象バージョン: 2026-07-13 時点の `main` ブランチ（コミット `b094363` 以降、フラグメント
エディタ追加後の `fragments/` ディレクトリを含む）。

---

## 1. Expand の基本動作のおさらい

1. Bond ツールで原子をホバー（またはホットスポットに設定）。
2. `` ` `` を押してラベル編集ボックスを開き、下記カタログの**表示名**（例: `TMS`）を
   そのまま入力して `Enter`。
3. 同じ原子をホバー（またはホットスポット）した状態で `x` または `X` を押す。
4. ラベル文字列と一致するフラグメントが見つかれば、その場で実構造に展開される
   （既存の結合は保持）。一致しなければ**何も起こらず、エラー表示もない**。

原子ショートカット表（[SHORTCUTS.ja.md §2-2](SHORTCUTS.ja.md#2-2-原子ショートカットホバー中の原子ホットスポットに適用)）に
デフォルトキーがある名前は、わざわざ Expand を使わずキー一発で配置できます。**Expand が
本当に必要になるのは、デフォルトキーが割り当てられていないフラグメント**（下表で
「既定キー: —」のもの）を使うときです。

> キーを割り当てたい場合は `chembuilder_config.json` の `atom_shortcuts` に
> `{ "key": "任意のキー", "fragment": "フラグメント名" }` を追記してください
> （`assets/default_config.json` と同じスキーマ）。

## 4. データ上の注意（`Ts` フラグメントの接続点）

`fragments/Ts.json` の `attach_idx` は **スルホニル硫黄 (S) ではなく、その先に追加された
炭素原子**を指しています（構造は `CH3-C6H4-SO2-C(attach)`）。他のアルキル鎖系フラグメント
（`Benz`, `TEG`, `C4H9`〜`C12H25`）と同じ「末端に接続点用の炭素を1つ追加する」パターンを
踏襲した結果と見られますが、Ts 基は通常スルホニル硫黄そのものが接続点になる想定（例:
アルコールの保護基として `R-O-Ts` を作る用途）です。**このフラグメントを Expand すると、
硫黄の手前に余分な炭素が1つ入った構造になる**点に注意してください。用途に応じて、
フラグメントエディタ（`cargo run --example fragment_editor`）で `Ts` を読み込み、
🎯 Set Attach でスルホニル硫黄を選び直して保存し直すことを推奨します。

## 5. 特殊名（フラグメントファイルではなくコード側で解決される名前）

`Config::resolve_fragment()`（`src/config.rs:279-295`）は、`fragments` 一覧に一致が無い場合、
以下の名前をコード側で特別扱いします。

| 表示名 | 効果 |
| --- | --- |
| `ring3` 〜 `ring12` | 指定サイズ（3〜12 員）の炭素環をその場で生成 |
| `benzene` | ベンゼン環を生成（`benzene.json` が存在するため通常はそちら経由で解決されるが、無い場合のフォールバックとしても機能する） |

`ring3`〜`ring12` は Expand 専用で、原子ショートカット表の環キー（`v`/`4`〜`8`）とは別経路
（あちらは `AtomAction::Ring` としてキーから直接環サイズを解決するため、フラグメント名
`ring5` 等を経由しない）です。ラベルに `ring6` などと手入力して `x` を押すことでも同じ
6 員環を生成できます。

## 7. 連続記述（フラグメント名を続けて書く）

ラベルが**単一のフラグメント名と一致しなかった場合に限り**、複数のフラグメント名を
**連結した文字列**として読み直します。読めたときは、それらが左から順に単結合でつながった
鎖に展開されます。

```
MeOPh   →  Me–O–Ph   （＝アニソール CH3–O–C6H5）
MeNO2   →  Me–NO2
EtOEt   →  Et–O–Et   （ジエチルエーテル）
```

- **左端のトークンが親原子に付きます**。`OMe` を書けば従来どおり O 側で結合するのと同じ
  向きです。
- 各フラグメントの**入口**は `attach_idx`、**出口**（次のフラグメントが結合する原子）は
  「入口から結合数で最も遠い非水素原子（同距離なら原子配列の先の方）」です。`Ph` なら
  *para* 位、`OMe` ならメチル炭素、`Et` なら末端 CH₃ になります。入口以外に非水素原子が
  無い `OH` / `NH2` などは入口そのものが出口です。
- **分割は最長一致＋バックトラック、大文字小文字を区別**します。`NO2` は `N`+`O`+`2` では
  なく `NO2`、`CO2Me` / `SiH3` / `TMS` / `CF3` も途中で切られません。`Ph`（フェニル）と
  `PH2`（ホスフィノ）は別物です。
- **読めない文字列は展開されません**（ラベルはそのまま残り、従来どおりエラー表示も出ません）。
  `Si` や `P` のような素の元素ラベルが勝手に鎖に化けることはありません。
- 単一のフラグメント名の挙動は**まったく変わりません**。連続記述は「従来なら何も起きなかった
  ラベル」だけが通る経路です。

親原子がすでに結合を持っている場合は、先頭フラグメントの原子価がその分埋まるだけです
（水素は分子データに保持されず、描画時に価数から数えられるため）。孤立原子上の `MeOPh` は
CH₃–O–C₆H₅、結合を1本持つ原子上の `MeOPh` は –CH₂–O–C₆H₅ になります。

実装は `src/label_chain.rs`（分割・合成）と `expand_label`（`src/widget/interact.rs`）です。

### 追加フラグメント: `Ph`

連続記述の実用に必須なため、**フェニル基 `Ph`**（`assets/fragments/Ph.json` /
`fragments/Ph.json`、接続点は *ipso* 炭素）を追加しました。構造は `benzene` と同じ 6 員環
ですが、`benzene`＝分子そのもの、`Ph`＝置換基という名前の使い分けです。

`Bn` / `Bz` などの他の慣用略号は**エイリアス機構を入れず**、必要になったら
`fragments/<名前>.json` を置くだけで連続記述からも使えるようにしてあります
（トークン候補はフラグメント名の一覧そのものです）。

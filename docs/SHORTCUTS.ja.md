# chembuider-rs キーボードショートカット一覧

マウス操作やツールバーを含む完全な操作マニュアルは [MANUAL.ja.md](MANUAL.ja.md) を参照して
ください。本書はキーボードショートカットのみを抜粋した早見表です。

対象バージョン: 2026-07-13 時点の `main` ブランチ（コミット `b094363` 以降）。
デフォルト値の出典は `assets/default_config.json`。

---

## 1. 共通（Select / Bond / Eraser のどのツールでも有効）

| キー | 効果 |
| --- | --- |
| `Ctrl` + `Z` | Undo（元に戻す） |
| `Ctrl` + `Y` または `Ctrl` + `Shift` + `Z` | Redo（やり直し） |
| `Ctrl` + `C` | コピー（選択が空なら分子全体をコピー） |
| `Ctrl` + `V` | ペースト |
| `Ctrl` + `K` | 2D クリーンアップの開始／中止（トグル） |
| `Ctrl` + `Shift` + `K` | 反応式のクリーンアップ（矢印を固定し、構造式を整形して矢印軸に上下中央揃え・均等配置。Undo 1 回で戻る） |
| `Ctrl` + `0` | 全体表示（分子全体がキャンバスに収まるようズームとパンを合わせる。クリーンアップ実行中も有効） |
| `Ctrl` + `1` / `2` / `3` | ツールを Select / Bond / Eraser に切り替え（数字キー単独の §2-2・§2-3 のショートカットとは別） |

> **テキスト入力中**（ラベル編集ボックスが開いている間、またはツールバーのテキスト欄に
> フォーカスがある間）は、`Ctrl`+`C`・`Ctrl`+`V`・`Ctrl`+`0` と §2〜§3 のツール別のキーが
> 無効になります。`Ctrl`+`Z`・`Ctrl`+`Y`／`Ctrl`+`Shift`+`Z`・`Ctrl`+`K`・`Ctrl`+`Shift`+`K`・`Ctrl`+`1`/`2`/`3` は
> テキスト入力中も効きます（`Ctrl`+`Z` などはキャンバスの Undo/Redo として実行されます）。
>
> **クリーンアップ実行中**は、§2〜§3 のツール別のキーが無効になります。この表のキーは
> すべて受け付けられます。実行中の `Ctrl`+`Z` はクリーンアップを取り消して開始前の構造に戻し、
> `Ctrl`+`Y`／`Ctrl`+`Shift`+`Z` と `Ctrl`+`V` はクリーンアップをその時点の配置で止めてから実行されます。

## 2. Bond ツール（デフォルトツール）

### 2-1. ナビゲーション・編集系

| キー | 対象 | 効果 |
| --- | --- | --- |
| `Delete` / `Backspace` | ホバー中の原子 or 結合（原子優先） | 削除 |
| `Enter` / `g` / `G` | ホバー中の原子 | ホットスポットに設定 |
| `Space` / `Tab` | – | ホットスポット解除 |
| `↑` `↓` `←` `→`（修飾キーなし） | ホットスポット原子 | 隣接原子のうち最も近い方向のものへホットスポットを移動 |
| `` ` ``（バッククォート） | ホバー中の原子、無ければホットスポット | インラインのラベル編集ボックスを開く（§5） |
| `x` / `X` | ホバー中の原子、無ければホットスポット | ExpandLabel: ラベルが既知のフラグメント名なら実構造に展開（§2-4） |

> これらのうち `` ` ``・`x`/`X`・下記の結合ショートカットは **Bond ツール専用**で、
> Select ツールでは反応しません。

### 2-2. 原子ショートカット（ホバー中の原子／ホットスポットに適用）

Select ツールでも、原子をホバーまたはホットスポットにしている場合は同じ表が使われます。

| キー | 動作 | キー | 動作 |
| --- | --- | --- | --- |
| `0` / `1` | 炭素を 1 個伸ばす | `3` | 炭素を 3 個伸ばす |
| `4`〜`8` | 4〜8 員の炭素環を配置/融合 | `v` | 3 員環 |
| `u` | 4 員環（`4` と同じ） | `a` / `P` | ベンゼン環 |
| `z` | ジグザグ鎖（炭素 2 個） | `Z` | ジグザグ鎖（炭素 4 個） |
| `2` | オキソ基（=O、カルボニル） | `o` | OH |
| `O` | 単独の O 原子 | `q` | OMe |
| `n` / `w` | NH₂ | `N` | 単独の N 原子 |
| `s` | SH | `S` | SiH₃ |
| `p` | PH₂ | `f` | F |
| `F` | CF₃ | `i` / `I` | I |
| `c` / `m` | Me（CH₃） | `C` / `l` | Cl |
| `L` | Li | `h` | H |
| `H` | Cbz | `b` | Br |
| `B` | BH₂ | `M` | MgBr |
| `d` | D（重水素） | `A` | Ac（アセチル） |
| `e` | Et | `E` | CO₂Me |
| `9` | N₃（アジド） | `Q` / `y` | Boc |
| `+` / `=` | 電荷 +1 | `-` | 電荷 −1 |

**対象原子の元素はどうなるか**（フラグメントのルート原子の元素で決まる）:

- ルートが**ヘテロ原子**（`o`=OH, `n`=NH₂, `q`=OMe など）→ 対象原子をその元素に**置き換える**
  （炭素の上で `o` → その炭素が O–H の O になる）
- ルートが**炭素**の骨格フラグメント（`a`/`P`、`4`〜`8`/`v`/`u`、`2`、`e`、`A`、`Q` など）
  → 対象原子の元素・電荷を**そのまま残す**。**N の上で `a` はピリジン**、O の上で `6` は
  テトラヒドロピラン。ただし H / D は保持されず炭素に置き換わる（水素は末端キャップのため）

**フラグメント由来の H は結合が増えると自動で消える**: `o`/`n`/`s`/`p`/`S` が連れてくる水素は
空いた原子価の代役なので、新しい結合や結合次数の増加でそこが埋まると超過分だけ自動削除される
（`n` の N 同士を二重結合 → アゾベンゼン、NH₂ の N に `a` → ピリジン）。しきい値は赤い過原子価
リングと同じ最大原子価。**`h` で明示的に置いた H は消えない**。既に飽和した S(VI) 中心では `s`
だけで裸の S になるので `Delete` は不要（押すと S 自体が消える）。

**ターゲット解決の優先順位**（同じキーでもホバー状態で挙動が変わる）:

1. 原子をホバー中 → その原子に適用
2. 原子もホバー結合も無いが、キーが「元素を表す」キー（`O`,`o`,`N`,`n`,`s`,`b` など単原子/非炭素
   ルートのフラグメント）→ カーソル位置に裸の原子を新規配置
3. 結合をホバー中（原子未ホバー時） → 下記の結合ショートカットを適用
4. どれもホバーしていないがホットスポットがある → ホットスポットに適用

### 2-3. 結合ショートカット（ホバー中の結合にのみ適用）

| キー | 動作 |
| --- | --- |
| `w` | 楔形結合（Wedge Up、手前向き） |
| `W` / `h` | 破線楔（Wedge Down、奥向き） |
| `H` / `b` / `B` | 太線結合（Bold） |
| `d` / `D` | 破線結合（Dashed） |
| `y` | 波線結合（Wavy、不定立体） |
| `1` / `2` / `3` | 結合次数を単/二重/三重に設定（立体表示は None にリセット） |
| `a` | ベンゼン環を融合（結合を 1 辺として共有） |
| `v` | 3 員環を融合 |
| `4`〜`9` | 4〜9 員環を融合 |
| `0` | 10 員環を融合 |

同じ立体キーをもう一度押すと立体表示は解除（None）に戻ります（トグル動作）。

### 2-4. ExpandLabel（`x` / `X`）— ラベルからフラグメントへの展開

原子のラベル文字列（`element` フィールド）がフラグメント名と**完全一致**（大文字小文字も区別）
していれば、`x` または `X` キーでその場でフラグメントの実構造に展開できます
（`expand_label()`, `interact.rs:1263-1289`）。

**使い方の典型例**:

1. Bond ツールで原子をクリックして配置（元素は炭素）。
2. その原子をホバーした状態で `` ` ``（バッククォート）を押し、ラベル編集ボックスに
   `Boc` のように**フラグメント名そのもの**を入力して `Enter`。ラベルが仮のテキスト
   `"Boc"` に置き換わる（この時点ではまだ構造は 1 原子のまま — 単なる文字列ラベル）。
3. その原子をホバー（またはホットスポットに）した状態で `x` を押すと、ラベルの
   `"Boc"` が実際の Boc 基（tert-ブトキシカルボニル、C₅H₉O₂ 相当の構造）に置き換わり、
   既存の結合はすべて保持される。

**照合の仕組みと注意点**:

- 照合先は `Config.fragments`（`assets/fragments/*.json` の組み込みフラグメント＋
  `fragments/*.json` のユーザー定義フラグメント、起動時に `Config::load()` でマージ）に
  加えて、特殊名 `benzene` と `ring3`〜`ring12`（3〜12 員の炭素環）。
- 一致は**完全一致**。フラグメント JSON 内の `"name"` フィールドの値と 1 文字も違わず
  一致する必要がある（例: `boc` や `BOC` ではヒットしない。`Boc` のみ）。
- 一致するフラグメントが見つからない場合は**何も起こらず、キーは静かに無視される**
  （エラー表示は出ない）。
- 展開時、フラグメントの接続原子（`attach_idx`）の元素・電荷が対象原子にコピーされ、
  周囲の既存結合を避ける向き（角度・反転）が自動選択されて挿入される
  （原子ショートカットでのフラグメント挿入と同じ配置ロジックを共有）。
- 利用可能なフラグメント名の一覧は `fragments/` ディレクトリ（またはフラグメントエディタの
  Load コンボボックス）で確認できる。標準搭載分の代表例: `Boc`, `Cbz`, `Ac`, `Et`, `Me`,
  `CF3`, `CO2Me`, `OMe`, `TMS`, `TBS`, `BPin`, `benzene` など。

## 3. Select ツール

| キー | 効果 |
| --- | --- |
| `Delete` / `Backspace` | 選択中の原子を削除。選択が空ならホバー中の原子/結合を削除 |
| `Enter`（原子ホバー中） | ホットスポットに設定 |
| `g` / `G`（原子ホバー中、無ければホットスポット） | ホットスポットに設定 **かつ選択にも追加**（Bond ツールとの違い） |
| `Space` / `Tab` | ホットスポット解除 |
| §2-2 の原子ショートカット | ホバー中/ホットスポットの原子に適用 |
| `↑` `↓` `←` `→`（修飾キーなし、ホットスポット時） | ホットスポットを隣接原子へ移動（ナビゲーションのみ） |
| `Ctrl` + 矢印 **または** `Shift` + 矢印（選択あり） | 選択群を 1 結合長ぶん平行移動（両者は同じ動作に重複割り当て） |
| `Alt` + `→` / `Alt` + `←`（選択あり） | 選択を ±15° 回転（`Alt`+`↑`/`↓` は未割り当て） |

## 5. ラベル編集の記法（`` ` `` キーで開く編集ボックス内）

| 記法 | 結果 |
| --- | --- |
| `_2` / `_{aq}` | 下付き文字（1 文字 または `{}` グループ） |
| `^+` / `^{2-}` | 上付き文字（1 文字 または `{}` グループ） |
| `**text**` | 太字 |
| `//text//` | 斜体 |
| `\x` | リテラル文字 `x`（エスケープ） |

例: `CO_2Et` → CO₂Et、`//t//Bu` → *t*Bu。`Enter` で確定、`Escape` でキャンセル。
